# Java Lab: Package Logging Levels Configuration

Duration : 60 Min.

## Scenario
Configure the logging subsystem level properties for the `org.springframework` framework package to target the DEBUG tracing resolution.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
1. Locate `application.properties`.
2. Configure the logging level properties configuration:
   `logging.level.org.springframework=DEBUG`
3. Save the file.

## Verification
Run the verification script to receive your score.

## Grading Criteria
Your performance will be evaluated based on the following test cases:

| Test Case | Requirement | Marks |
| --------- | ----------- | ----- |
| **TC1**   | `application.properties` exists | 3.33 Marks |
| **TC2**   | logging level config property defined | 3.33 Marks |
| **TC3**   | logging level set exactly to DEBUG | 3.34 Marks |

**Total Score: 10 Marks**
