# Enterprise Batch Lab: AutoSys Job Information Language (JIL) Design

Duration : 90 Min.

## Scenario
A DevOps team requires a multi-job workflow defined via declarative JIL scripts to automate deployments.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Write JIL scripts defining boxes, standard jobs, custom calendars, and run-window restrictions.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Defining parent box structures and child job relationships: 3 marks
2. Configuring execution conditions (e.g. success of predecessor): 3 marks
3. Defining specific calendar-day exclusion rules: 3 marks
4. Specifying custom resource profiles and environment files: 3 marks
5. Specifying log file paths and redirection variables: 2 marks
6. Configuring alert notification thresholds and criteria: 2 marks
7. Formulating rapid fail recovery command properties: 2 marks
8. Ensuring clean JIL syntax validation: 2 marks

**Total Score: 20 Marks**

- Ensure all logs and configurations are fully saved in your workspace folder before submitting.
