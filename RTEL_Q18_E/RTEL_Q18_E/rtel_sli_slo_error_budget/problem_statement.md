# Observability Lab: Defining SLIs, SLOs & Error Budget Consumption Metrics

Duration : 30 Min.

## Scenario
A Site Reliability Engineering (SRE) team needs to establish Service Level Objectives (SLOs) and Error Budgets for an API service.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Define Service Level Indicators (SLIs), set realistic SLO targets, and calculate monthly Error Budget burn rates.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Defining valid Service Level Indicators (SLIs) for availability and latency: 3 marks
2. Calculating monthly Error Budget allowances based on target SLO percentages: 3 marks
3. Tracking Error Budget burn rate acceleration during incident windows: 2 marks
4. Formulating policy rules for freezing feature deployments upon budget depletion: 2 marks

**Total Score: 10 Marks**
