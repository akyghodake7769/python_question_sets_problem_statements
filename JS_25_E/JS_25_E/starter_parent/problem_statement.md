# Java Lab: Maven Parent Project Configuration

Duration : 60 Min.

## Scenario
Define the standard spring boot starter parent dependency inside `pom.xml`.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
1. Locate `pom.xml`.
2. Configure a `<parent>` project coordinate mapping:
   - `<groupId>org.springframework.boot</groupId>`
   - `<artifactId>spring-boot-starter-parent</artifactId>`
   - `<version>3.1.5</version>`
3. Save the file.

## Verification
Run the verification script to receive your score.
