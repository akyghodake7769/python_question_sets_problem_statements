# Java Lab: Kubernetes ConfigMaps and Secrets

Duration : 60 Min.

## Scenario
Define a basic Kubernetes ConfigMap resource file named `configmap.yaml` to store application configurations.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
1. Locate or create `configmap.yaml`.
2. Define a ConfigMap metadata object name value:
   `name: app-config`
3. Save the file.

## Verification
Run the verification script to receive your score.

## Grading Criteria
Your performance will be evaluated based on the following test cases:

| Test Case | Requirement | Marks |
| --------- | ----------- | ----- |
| **TC1   | `configmap.yaml` exists | 3 Marks |
| **TC2   | `kind` attribute set to ConfigMap | 3 Marks |
| **TC3   | `metadata.name` set exactly to app-config | 4 Marks |

**Total Score: 10 Marks**
