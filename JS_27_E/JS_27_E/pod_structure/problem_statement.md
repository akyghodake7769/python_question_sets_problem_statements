# Java Lab: Kubernetes Java Pod Configuration

Duration : 60 Min.

## Scenario
Define the basic Kubernetes container image for running Java applications in a Pod manifest.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
1. Locate or create `pod.yaml`.
2. Define the container spec image parameter to target the official JDK runtime:
   `image: openjdk:17`
3. Save the file.

## Verification
Run the verification script to receive your score.

## Grading Criteria
Your performance will be evaluated based on the following test cases:

| Test Case | Requirement | Marks |
| --------- | ----------- | ----- |
| **TC1   | `pod.yaml` exists | 3 Marks |
| **TC2   | container definition spec present | 3 Marks |
| **TC3   | image set exactly to openjdk:17 | 4 Marks |

**Total Score: 10 Marks**
