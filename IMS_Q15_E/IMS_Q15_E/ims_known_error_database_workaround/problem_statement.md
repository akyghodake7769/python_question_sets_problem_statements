# Incident Management Lab: Known Error Database (KEDB) & Workaround Documentation

Duration : 45 Min.

## Scenario
Recurring software bugs cause periodic service degradations. You must document temporary workarounds in the KEDB.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Create KEDB entries, document temporary workarounds, and establish linkage between incident tickets and permanent fixes.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Authoring structured Known Error Database (KEDB) articles for recurring software bugs: 2 marks
2. Documenting step-by-step temporary workaround procedures for service desk agents: 2 marks
3. Linking incident tickets to matching Known Error records to accelerate MTTR: 2 marks
4. Tracking Known Error resolution progress with software engineering teams: 2 marks
5. Validating workaround effectiveness and updating KB expiration dates: 2 marks

**Total Score: 10 Marks**
