# Enterprise Batch Lab: Cross-Platform Dependency Orchestration

Duration : 90 Min.

## Scenario
Mainframe file updates must trigger a cloud-based Python transformation script. The integration agent is disconnected.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Configure file-watcher agents, cross-platform dependencies, and secure transfer checkpoints.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Setting up secure file-watcher trigger event conditions: 3 marks
2. Mapping file detection events to remote server execution runs: 3 marks
3. Customizing SSH agent keys and transfer validation parameters: 3 marks
4. Creating cross-system execution retry policies: 3 marks
5. Documenting cleanup policies for temporary staging files: 2 marks
6. Establishing alert triggers for file delivery delays: 2 marks
7. Customizing logging output formats across boundaries: 2 marks
8. Ensuring data integrity validation via checksum files: 2 marks

**Total Score: 20 Marks**
