# SharePoint Lab: Power Automate Approval Gateways

Duration : 90 Min.

## Scenario
Procurement files exceeding $10,000 require multi-stage executive approvals before release.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Build a multi-stage approval gateway with concurrency controls and email status updates.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Flow triggers and conditional branch routing: 3 marks
2. Multi-stage sequential approvals pipeline: 3 marks
3. Concurrency limits and timeout reminders configuration: 3 marks
4. Updating list metadata fields dynamically: 3 marks
5. Handling rejected approval transition paths: 2 marks
6. Integrating Teams approval cards: 2 marks
7. Dynamic email notifications with context links: 2 marks
8. Flow run error logging validation: 2 marks

**Total Score: 20 Marks**
