# Incident Management Lab: Multi-Service Outage PIR & Problem Record Lifecycle

Duration : 90 Min.

## Scenario
A SAN storage failure cascades across payment, authentication, and inventory microservices. You must facilitate a multi-team PIR.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Analyze multi-service failure timelines, isolate root causes vs contributing factors, and manage the Problem Record lifecycle.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Constructing a multi-service chronological outage timeline across 3 platform tiers: 3 marks
2. Differentiating primary root causes from secondary contributing infrastructure factors: 3 marks
3. Facilitating a cross-functional PIR workshop with Storage, DB, and App teams: 3 marks
4. Authoring a comprehensive Post Incident Review (PIR) document with technical evidence: 3 marks
5. Raising and managing Problem Records through Root Cause Analysis to Known Error state: 3 marks
6. Establishing permanent preventative actions and assigning SMART action owners: 3 marks
7. Validating problem resolution sign-offs before closing Problem Records: 2 marks

**Total Score: 20 Marks**
