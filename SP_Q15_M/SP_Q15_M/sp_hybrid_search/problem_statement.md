# SharePoint Lab: Hybrid Search Architecture Setup

Duration : 90 Min.

## Scenario
You are implementing a hybrid environment. You need to enable users to search both SharePoint Server on-premises and SharePoint Online content simultaneously.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Configure a Cloud Search Service Application (SSA) and map hybrid search indexes.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Cloud Search Service Application creation: 3 marks
2. Hybrid search crawl topology setup: 3 marks
3. Cloud SSA connection to M365 tenant: 3 marks
4. Search schema managed properties mappings: 3 marks
5. Hybrid query federation configuration: 2 marks
6. Content source security filtering: 2 marks
7. Hybrid crawl log verification: 2 marks
8. Search result ranking configuration: 2 marks

**Total Score: 20 Marks**
