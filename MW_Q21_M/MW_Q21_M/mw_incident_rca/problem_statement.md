# Middleware Lab: Production Outage Incident Resolution

Duration : 90 Min.

## Scenario
A payment processing API Gateway went offline. Operations must correlate logs and diagnostics metrics to identify the trigger.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Draft a production incident response report detailing timeline, logs diagnostics, root cause, and mitigations.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Constructing a chronological timeline of outage events: 5 marks
2. Correlating system CPU spikes with thread exhaustion logs: 5 marks
3. Drafting immediate temporary workaround and long-term fix steps: 5 marks
4. Structuring stakeholder communication and escalation notifications: 5 marks

**Total Score: 20 Marks**

## Important Notes
- This is a manually evaluated question.
- Ensure all logs and configurations are fully saved in your workspace folder before submitting.
