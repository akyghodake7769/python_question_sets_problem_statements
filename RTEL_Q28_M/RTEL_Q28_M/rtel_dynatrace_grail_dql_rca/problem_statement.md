# Observability Lab: Enterprise Application Crash Analysis via Dynatrace DQL

Duration : 90 Min.

## Scenario
An enterprise SAP integration portal suffers periodic crashes. You must query Dynatrace Grail using DQL to perform root cause analysis.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Construct complex DQL queries, evaluate Davis AI root cause cards, inspect log records in Grail, and draft an incident remediation plan.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Evaluating Dynatrace Davis AI problem cards to identify root cause recommendations: 3 marks
2. Constructing complex DQL queries joining log records and metric events in Grail: 3 marks
3. Filtering process crash dumps and out-of-memory events by host entities: 3 marks
4. Analyzing Smartscape dependency maps to evaluate upstream service impact: 3 marks
5. Calculating MTTR (Mean Time to Resolution) metrics for the affected portal: 2 marks
6. Configuring custom DQL alert anomaly detectors to catch early memory degradation: 2 marks
7. Drafting a comprehensive incident mitigation runbook for operations teams: 2 marks
8. Formatting query results and telemetry charts into a executive summary PDF: 2 marks

**Total Score: 20 Marks**
