# SharePoint Lab: Guest Sharing & Governance Policy

Duration : 90 Min.

## Scenario
Data leaks have been detected. You must lock down guest access on sensitive site collections, implement domain restrictions, and set up automatic access expiration reviews.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Define guest invite permissions, enforce allowed domain policies, and set access review schedules.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. External sharing domain whitelist/blacklist config: 3 marks
2. Guest access expiration policy configurations: 3 marks
3. SharePoint site collection classification labeling: 3 marks
4. Access Reviews lifecycle scheduling: 3 marks
5. Sensitive data classification policies check: 2 marks
6. Anonymous link disablement and timeout config: 2 marks
7. Auditing guest invitation operations: 2 marks
8. Proactive access review logs verification: 2 marks

**Total Score: 20 Marks**
