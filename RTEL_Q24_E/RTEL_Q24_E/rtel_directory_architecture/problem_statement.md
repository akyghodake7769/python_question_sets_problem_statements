# Observability Lab: Observability Agent & Collector Directory Architecture

Duration : 45 Min.

## Scenario
A system auditor requires auditing OpenTelemetry Collector and Promtail configuration file layouts and log output paths.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
- Document standard directory locations for OpenTelemetry Collectors, Promtail, and Vector pipelines.

## Instructions to Perform the Task
1. When your workspace loads in **VS Code**, use the **Explorer** panel on the left to locate your files.
2. Navigate to and click the specific files mentioned in the Task Objectives.
3. Make the necessary code edits in the editor.
4. Press `Ctrl + S` (Windows) or `Cmd + S` (Mac) to save your changes.
5. If you need to run commands, open the built-in terminal by clicking **Terminal > New Terminal** from the top menu.

## Validation
Once you have saved your files and are ready to submit, return to the platform dashboard and click the **"Submit Final"** button. This task is evaluated manually by the grading team.

## Evaluation Rubric:
1. Mapping directory layouts for telemetry collector configs and binaries: 2 marks
2. Identifying primary YAML configuration entrypoint files: 2 marks
3. Configuring local buffer and file storage paths for telemetry pipelines: 2 marks
4. Verifying service startup logs and daemon systemd unit statuses: 2 marks
5. Validating agent permission settings for host log access: 2 marks

**Total Score: 10 Marks**
