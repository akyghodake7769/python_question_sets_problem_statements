# Java Lab: YAML Format Properties Configuration

Duration : 60 Min.

## Scenario
Convert standard flat properties configuration to standard YAML format in Spring Boot.

## Task Objectives
Perform the following actions inside the `student_workspace` directory:
1. Create a file named `application.yml`.
2. Define the port configuration to 8080 under the server namespace:
   ```yaml
   server:
     port: 8080
   ```
3. Save the file.

## Verification
Run the verification script to receive your score.

## Grading Criteria
Your performance will be evaluated based on the following test cases:

| Test Case | Requirement | Marks |
| --------- | ----------- | ----- |
| **TC1   | `application.yml` exists | 3 Marks |
| **TC2   | `server` root key is present | 3 Marks |
| **TC3   | `port` is set to 8080 | 4 Marks |

**Total Score: 10 Marks**
